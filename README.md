## 🚀 Overview

**ClassroomLM** is an interactive virtual learning environment designed to solve passive reading fatigue. Instead of staring at long text walls, ClassroomLM transforms your materials into step-by-step visual lessons.

### ✨ Key Features
- 👩‍🏫 **AI Teacher Avatar:** Explains complex concepts visually in an interactive classroom setting.
- 🖍️ **Digital Whiteboard:** Dynamically visualizes formulas, steps, and key concepts in real time.
- 💬 **Real-Time Q&A:** Pause any lesson to ask clarifying questions whenever you get stuck.
- 🎮 **Knowledge Quizzes:** Auto-generates practice questions to test retention before you finish.
